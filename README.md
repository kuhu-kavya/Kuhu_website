# Kuhu_website

Kuhu's design portfolio, built with React and Vite.

Live site: https://kuhu-kavya.github.io/Kuhu_website/

## Run it on your computer

You need [Node.js](https://nodejs.org) installed. In a terminal, inside this folder:

```bash
npm install     # first time only: downloads React and Vite
npm run dev     # starts a local preview, open the link it prints
```

Edit `src/App.jsx` and the preview updates as soon as you save.

## Publish changes

Push to the `main` branch on GitHub. The workflow in `.github/workflows/deploy.yml`
builds the site and publishes it to GitHub Pages automatically (takes about a minute).
